# MVP v0.1

## Objetivo

O MVP (Minimum Viable Product) tem como objetivo validar a arquitetura da Nebula Platform, permitindo a ativação de dispositivos, distribuição centralizada de playlists e reprodução de conteúdo através do Nebula Player.

Nesta fase, o foco não é possuir todas as funcionalidades de um player IPTV completo, mas validar toda a comunicação entre os módulos da plataforma.

---

# Escopo

O MVP contempla:

- Nebula Player (Android)
- Nebula Core
- Painel Administrativo
- Banco de Dados
- Telemetria básica

---

# Funcionalidades

## Nebula Player

### Identificação

O aplicativo deverá gerar automaticamente uma **Device Key** durante a primeira instalação.

Também deverá obter o **MAC Address** do dispositivo sempre que disponível pela plataforma.

Ambos serão utilizados durante o processo de ativação.

---

### Ativação

Ao iniciar pela primeira vez o aplicativo deverá exibir:

- Device Key
- MAC Address
- Status da ativação

Enquanto o dispositivo não estiver ativado, nenhuma playlist poderá ser carregada.

---

### Comunicação

O Player deverá comunicar-se exclusivamente com o Nebula Core.

Em nenhuma hipótese o usuário poderá cadastrar:

- Playlist M3U
- Credenciais Xtream
- URLs
- Servidores

Toda configuração será realizada pelo Painel Administrativo.

---

### Reprodução

Após ativado, o Player deverá:

- Solicitar a playlist ao Nebula Core
- Carregar categorias
- Permitir reprodução dos canais
- Reconectar automaticamente em caso de falha
- Exibir mensagens de erro amigáveis

---

# Nebula Core

Responsável por:

- validar dispositivos;
- autenticar requisições;
- localizar a playlist vinculada;
- distribuir a playlist ao Player;
- registrar eventos;
- disponibilizar APIs.

---

# Painel Administrativo

Nesta primeira versão será possível:

## Clientes

- cadastrar clientes;
- editar clientes;
- bloquear clientes.

## Dispositivos

- visualizar dispositivos;
- ativar dispositivos;
- bloquear dispositivos;
- visualizar Device Key;
- visualizar MAC Address.

## Playlists

- cadastrar playlists;
- editar playlists;
- remover playlists;
- vincular playlists aos dispositivos.

## Servidores

- cadastrar servidores;
- editar servidores;
- habilitar/desabilitar servidores.

---

# Banco de Dados

O MVP deverá possuir pelo menos as seguintes entidades:

- Users
- Clients
- Devices
- Servers
- Playlists
- Telemetry
- Logs

---

# Telemetria

O Player deverá enviar periodicamente:

- Heartbeat
- Ping
- Tempo de Loading
- Buffering
- Canal reproduzido
- Tempo assistido
- Erros

---

# Fora do Escopo

Não fazem parte do MVP:

- iOS
- Apple TV
- Samsung Tizen
- LG webOS
- Controle parental
- Favoritos sincronizados
- Download de conteúdo
- Multiusuário
- IA
- Marketplace
- Pagamentos

---

# Critérios de Aceite

O MVP será considerado concluído quando:

- Um dispositivo puder ser ativado.
- A playlist puder ser vinculada pelo Painel Administrativo.
- O Player conseguir obter a playlist através do Nebula Core.
- Um canal puder ser reproduzido.
- A telemetria básica estiver chegando ao backend.
- O administrador conseguir visualizar os dispositivos cadastrados.

---

# Princípios do MVP

- O Player nunca armazena playlists permanentemente.
- Toda regra de negócio pertence ao Nebula Core.
- Todo gerenciamento ocorre pelo Painel Administrativo.
- A telemetria deve ser transparente e configurável.
- O sistema deve ser preparado para múltiplos servidores.
