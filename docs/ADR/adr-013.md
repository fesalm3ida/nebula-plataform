# ADR-013

## Título

Separação entre armazenamento local dos módulos clientes e banco transacional da Nebula Platform

---

## Status

Aceito

---

## Contexto

Durante a modelagem física do módulo Nebula Player surgiu a dúvida sobre a viabilidade de utilizar PostgreSQL no aplicativo Android.

Foi identificado que o Nebula Player, por ser um aplicativo cliente Android/APK, não deve acessar nem executar PostgreSQL diretamente.

O banco transacional principal da Nebula Platform pertence ao backend, especialmente ao Nebula Core.

---

## Decisão

A Nebula Platform adotará separação clara entre:

- armazenamento local dos módulos clientes;
- banco transacional central da plataforma.

O Nebula Player utilizará apenas armazenamento local leve para dados permitidos pela arquitetura.

O Nebula Core será o responsável por acessar o banco transacional PostgreSQL.

---

## Arquitetura

```text
Nebula Player Android
        │
        │ API HTTP
        ▼
Nebula Core
        │
        ▼
PostgreSQL
```
