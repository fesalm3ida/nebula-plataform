# Documento

**Projeto:** Nebula Platform

**Documento:** Principios

**Versão:** 0.1.0

**Data de Atualização:** 01/07/2026


# Princípio 1
> O Nebula Player é apenas um cliente de reprodução.

# Princípio 2
> Toda regra de negócio pertence ao Nebula Core.

# Princípio 3
> Todo recurso de conteúdo autorizado é disponibilizado pelo Nebula Core.

# Princípio 4
> O Player nunca armazena permanentemente recursos de conteúdo autorizados.

# Princípio 5
> Toda comunicação ocorre através das APIs oficiais.

# Princípio 6
> O Monitor nunca interfere na reprodução.

# Princípio 7
> Toda decisão arquitetural importante gera um ADR.

# Princípio 8
> Ideias ainda não aprovadas permanecem como RFC.

# Princípio 9
> O código implementa decisões.Nunca o contrário.

# Princípio 10
> Antes de qualquer funcionalidade existir, ela deve possuir documentação.
