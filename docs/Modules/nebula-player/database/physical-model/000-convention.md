# Convenções do Modelo Físico

## Nomenclatura

As tabelas serão nomeadas em `snake_case` e no plural.

Exemplos:

- `clients`
- `devices`
- `sessions`
- `telemetry_events`

## Colunas

As colunas também seguirão `snake_case`.

Exemplos:

- `device_id`
- `client_id`
- `created_at`
- `updated_at`

## Identificadores

Todas as entidades principais utilizarão UUID como identificador.

Exemplo:

- `device_id`
- `session_id`
- `authorization_id`
